# Tesla Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing Tesla sales performance using Microsoft Power BI. The dashboard provides insights into sales trends, production, marketing expenditure, and website traffic.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

## Dashboard Features
- Total Sales
- Total Marketing Spend
- Total Website Traffic
- Total Production
- Monthly Sales Trend
- Yearly Sales Analysis
- Seasonal Sales Distribution
- Sales Performance Analysis using Scatter Chart

## Project Objectives
- Analyze Tesla sales performance over time.
- Identify monthly and yearly sales trends.
- Understand seasonal sales patterns.
- Monitor production and marketing performance.
- Present business data through interactive visualizations.

## Dashboard Visualizations
The dashboard includes KPI cards, line charts, column charts, pie charts, and scatter charts to provide a clear overview of Tesla's sales performance.
